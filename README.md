# HTTP Server + SQLite

REST API сервер на Go со стандартной библиотекой.

## Стек
Go 1.22+
SQLite (modernc.org/sqlite)
Чистый net/http

## Эндпоинты
GET /api/info — информация о сервере
GET /api/time — текущее время (UTC)
POST /api/messages — сохранить сообщение в БД
GET /api/messages — получить все сообщения из БД
404 на все остальные запросы

## Что сделано
Подключена база данных (автоматическое создание таблицы при старте)
Реализован полный цикл обработки запроса: контроллер → БД → JSON-ответ
Настроена обработка ошибок и корректные HTTP-статусы
Код разделён на логические файлы (db, handlers, errors)
Проект полностью готов к деплою и расширению

## Запуск
go run .
